# -AI-for-Smart-Cities
Real-Time Monitoring of Air Pollution &amp; Waste Management
This project leverages the power of Artificial Intelligence to build a smarter, greener city through real-time monitoring of air pollution and waste management. Developed as part of a B.Tech final-year project at Tula’s Institute, Dehradun, under the guidance of Mr. Sharad Pratap Singh.

🚀 Key Features
📊 Real-time Pollution Tracking using historical NAMP dataset (2011–2015)

🧠 Machine Learning Models to analyze and predict pollution levels

🗺️ Interactive Maps & Dashboards for location-based monitoring

🗑️ Smart Waste Management Interface to track and manage waste levels

📈 Pollution & Waste Stats visualized via Chart.js/Plotly

🧩 Modular UI with modals, charts, popups, and dynamic updates

🛠 Tech Stack
Frontend: React.js + Tailwind CSS

Backend: Python (Flask) + ML (scikit-learn, pandas)

Data Visualization: Chart.js / Plotly

Dataset: Central Pollution Control Board – NAMP (2011–2015)
